# Galería El Ecléctico - Sitio Web

Sitio web oficial de Galería El Ecléctico, creado con HTML y CSS puro, sin dependencias de JavaScript.

## 🌟 Descripción

Galería comercial moderna con diversas opciones de compras, gastronomía y entretenimiento para toda la familia.

## 📁 Estructura del Proyecto

```
GaleriaComercial-DyDW/
├── index.html              # Página de inicio
├── gastronomia.html        # Restaurantes y cafeterías
├── locales.html            # Locales comerciales
├── ofertas.html            # Promociones y descuentos
├── servicio.html           # Servicio al cliente
├── entretenimiento.html    # Cine, juegos y actividades
├── contacto.html           # Formulario y asistente virtual
├── styles.css              # Estilos CSS globales
├── assets/                 # Imágenes y recursos
│   └── logo.png           # Logo de la galería
├── .gitignore             # Archivos ignorados por Git
└── README.md              # Este archivo
```

## 🚀 Cómo Usar

### Método 1: Abrir directamente
Simplemente abre `index.html` en tu navegador favorito.

### Método 2: Servidor local (recomendado)
Para evitar problemas con rutas relativas, usa un servidor local:

```bash
# Con Python 3
python -m http.server 8000

# Con Node.js (si tienes http-server instalado)
npx http-server

# Con PHP
php -S localhost:8000
```

Luego abre tu navegador en `http://localhost:8000`
