# Assets

Coloca aquí las imágenes y recursos del proyecto.

## Logo

El logo de "Galería El Ecléctico" debe colocarse en esta carpeta con el nombre `logo.png`.

Puedes copiar el logo desde el proyecto React original ubicado en:
`src/assets/75761f79889f9a867502d39600b224511cef5308.png`

O crear/agregar tu propio logo con el nombre `logo.png` en esta carpeta.

## Estructura recomendada

```
assets/
├── logo.png          # Logo principal
├── favicon.ico       # (opcional) Favicon del sitio
└── images/           # (opcional) Otras imágenes
```
